首次使用或忘记密码

全新安装会自动生成管理员用户名与密码，并在终端显示；升级保留已有账户。请使用安装时保存的凭据，没有通用默认密码。

忘记密码时，在服务器上使用面板专用服务用户、活动版本的 Python 环境及相同的 VUI_DATA_DIR，交互重置已有账户：

python -m app.admin set-password your_admin

将 your_admin 替换为实际用户名；不要把密码写入命令参数。请先核对当前服务的运行用户、Python 路径和数据目录，避免操作另一套账户数据。
