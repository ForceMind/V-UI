添加连接域名

将域名的 A / AAAA 记录指向此 VPS，并允许公网访问 80 端口。由一键安装器准备 HTTP-01 验证服务。已有网站占用 80 时不能强行覆盖。

DNS验证不要求开放80端口，也不会关闭其他证书使用的80端口。签发只证明域名控制；实际连接域名仍需配置指向本机的A/AAAA记录，不会自动修改这些记录。

Cloudflare凭据（仅管理员）

在Cloudflare创建仅限指定域名的API Token，权限为Zone → DNS → Edit、Zone → Zone → Read。不要使用Global API Key。保存时只核对域名，不创建测试记录。Token仅写入；续期所需文件会进入完整私有备份，该备份未加密，请妥善保存。

遗留的DNS验证记录（仅管理员）

这里处理本次验证留下的TXT记录。清理只使用对应Cloudflare凭据处理本任务自己的记录，不重新签发证书，不删除其他TXT。写入结果不明时先刷新核对，勿反复提交。

系统无法确认未知写入没有残留时，会继续保留待清理状态。只有你已在Cloudflare核对并确认没有残留，才使用人工确认；人工确认不等于系统自动清理成功。

签发成功不等于所有绑定均已应用，请查看每个使用位置的状态。

03 · 使用说明

新建节点时可选择托管证书。已有受支持的 sing-box TLS 与 Xray VLESS/TCP/TLS 节点可在证书卡片中绑定。续期不会主动启动你手动停止的核心；应用失败会保留旧运行配置并显示待处理。

“应用到面板”只接受正式环境、且与当前面板域名一致的证书。热更新只影响新连接，不要求退出后台。HTTP-01 的 80 端口不提供面板登录或任意文件。
