# 3X-UI 中文精简版

基于 [3X-UI v3.11.0](https://github.com/MHSanaei/3x-ui/releases/tag/v3.11.0)。管理员面板、安装入口和主要运维菜单使用简体中文。安装包面向使用 systemd 的 Linux x86_64 主机。

## 一条命令安装

在线入口读取本分支的 `packages/stable.txt`，从清单指定的提交下载完整的同版本安装包并校验 SHA-256。入口使用服务器上的 Bash 和 curl。

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/ForceMind/V-UI/3x-ui-zh-lite/install-online.sh)
```

默认一键安装直接完成，使用 SQLite。需要附加功能时，可在命令后加 `--ssl example.org`、`--postgres`、`--fail2ban` 或 `--port 2053`，也可在安装后打开中文运维菜单。证书的 HTTP 验证需要服务器的 80 端口可达，域名需正确解析到本机。Cloudflare DNS 验证可从 `x-ui` 证书菜单发起。

默认新装监听所有 IPv4 网卡的 `2053` 端口。安装器显示随机账号、密码，以及根据检测到的公网 IPv4 和实际端口、路径生成的管理地址。若自动检测失败，使用云控制台显示的公网 IP 和终端给出的端口与路径。直连需要主机端口与云安全组允许访问。HTTP 登录为明文，可使用 `--ssl` 或从运维菜单配置 HTTPS。

显式使用 `--ssl` 时，面板在通过 HTTPS 验证后才开放到其他网卡。签发或验证失败时可通过 SSH 转发访问本机地址，并从证书菜单重试。

在 `zh.5` 或更早的中文版上已经完成新装且希望直接访问的用户，可以运行 `sudo x-ui`，选 `24`「SSH 端口转发说明」，再选 `2`「清除监听 IP」。管理地址使用服务器公网 IP 及原端口与路径。

## 从已有的原版 3X-UI 迁移

原版 `v3.11.0` 和 `v2.9.2` 都可以用下面一条命令迁移到中文版。适用条件是官方脚本安装、Linux x86_64、systemd、以 root 运行的服务和 SQLite 数据库。在原服务器的 Bash 中执行，保留现有安装和数据目录。

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/ForceMind/V-UI/3x-ui-zh-lite/install-online.sh) --migrate
```

预检读取当前服务、程序版本和实际数据库位置。通过后会短暂停服，备份原程序、管理脚本、服务配置和 SQLite 数据（含仍存在的 WAL），沿用原账号、面板端口、登录路径、证书、节点和自定义核心文件。迁移结束会打印备份目录。启动检查失败时，脚本会尝试恢复备份并报告恢复结果。原本停止的服务会保持停止。

跨主版本迁移会先在数据库副本上升级并核对数据。遇到无法证明等价的自定义路由会中止并给出原因。Docker、上文以外的版本、已有 PostgreSQL 以及无法识别的定制服务布局会在预检时被拒绝。中文版新安装时可选择 PostgreSQL。迁移后用 `sudo x-ui` 打开中文管理菜单。

## 运维功能

运行 `sudo x-ui` 打开数字菜单。也可直接运行 `sudo x-ui 证书`、`sudo x-ui 测速`、`sudo x-ui BBR`、`sudo x-ui 防火墙`、`sudo x-ui Fail2ban` 或 `sudo x-ui PostgreSQL`。

| 功能 | 用途 |
| --- | --- |
| 自动证书 | 域名和 IPv4 证书签发、续期、现有证书绑定、Cloudflare DNS 验证。自动安装的证书保存在 `/etc/x-ui-managed-certs`，私钥限 root 与面板服务组读取。 |
| 测速、BBR、防火墙 | 运行 Ookla Speedtest、调整 BBR、管理指定防火墙端口。由管理员在菜单中主动选择。 |
| Fail2ban | 安装及管理节点 IP 限制，在菜单查看封禁记录。 |
| PostgreSQL | 安装服务器并创建面板专用数据库，保留 SQLite 默认选项和已有迁移入口。 |
| 备份 | `sudo x-ui 备份 /root/x-ui-backup.tar.gz` 保存本地数据目录。PostgreSQL 数据通过面板数据库导出，或使用对应的 `pg_dump`。 |
| 更新 | `sudo x-ui 更新` 通过本分支清单更新。传入解包目录可离线更新，保留数据库和现有设置。 |
| 节点批量升级 | 主面板向选中的启用且在线节点发起面板软件更新，记录逐台受理或失败结果。节点自行选择发行渠道，官方节点使用官方渠道，中文版节点使用中文包。受理后的实际版本可在节点刷新后核对。 |

自动签发失败时可继续用 SSH 登录，再从证书菜单重试。系统命令、ACME、Xray 等原始诊断由对应组件输出，部分上游细节提示仍保留原文。

## 本次精简

- 移除了登录页和概览页的赞助广告、赞助页面、赞助接口，以及侧栏捐赠按钮。
- 管理员面板使用简体中文，客户端订阅页保留语言切换。
- 测速、BBR、防火墙、证书、Fail2ban、PostgreSQL、节点批量升级以及地区规则均保留。其他功能的精简需要逐项确认。

## 离线安装或更新

传输同一版本的完整安装包与 `.sha256` 到目标服务器。以 `zh.6` 为例：

```bash
sha256sum -c 3x-ui-v3.11.0-zh.6-linux-amd64.tar.gz.sha256
tar -xzf 3x-ui-v3.11.0-zh.6-linux-amd64.tar.gz
cd 3x-ui-zh-lite
sudo bash install.sh
```

已有本分支安装时运行 `sudo bash update.sh`。全新安装会检查旧面板和保留数据。源码安装包构建入口为 `bash 制作安装包.sh`，使用 Go 1.27.3、Node.js 26、npm 11、GCC 和 Linux x86_64。`XUI_UPSTREAM_ARCHIVE` 可以指定已校验的官方归档缓存。

本轮工作补充已有原版服务器迁移和中文操作提示。验收项目包括已有数据的预检、备份、替换、出错回退、中文运维说明与可下载的对应版本。旧版 `zh.3` 仅适用于新装或该中文版自身更新。

首次 Ubuntu 验收已通过新装与随机账号登录。3.11.0 的测试在读取环回流量统计时中止，2.9.2 在旧面板的基线代理探测时中止。本次运行结果保留在[首次迁移验收](https://github.com/ForceMind/V-UI/actions/runs/45788870962)。

对齐测试机的 root 命令目录权限后，3.11.0 的真实迁移、重复执行和故障回退通过，既有账号和客户端仍可使用。2.9.2 的原程序也通过了真实 VLESS 连接，但副本升级检测到上游默认 Xray 模板发生变化并中止替换。见[权限预检](https://github.com/ForceMind/V-UI/actions/runs/45792660533)和[第四次验收](https://github.com/ForceMind/V-UI/actions/runs/45793410714)。

### 流量统计优化候选

本轮范围为共享在线用户查询、批量累加本机客户端流量及与原版 `3.11.0` 的同机对比。稳定入口继续使用 `zh.6`。

在线快照对同一核心最多复用 2 秒，覆盖流量与客户端 IP 任务，保持各自的 5 秒和 10 秒检查周期。批量写入在原计费事务内累加活跃客户端的流量，每批最多 299 行。沿用身份归并、流量上限、最近在线时间、原子累加和计费后独立维护限额及续期的流程。Windows 上的定向回归已覆盖共享查询、瞬时错误、核心代际、两批写入、第二批失败的完整回滚，以及与限额、续期、IP 统计相关的既有测试。

整机对比入口为 `scripts/compare-zh-traffic.py`，使用同一官方核心和同一 SQLite 初始数据，比较单连接、多并发和配额耗尽。正式验收以 `x-ui` 和 Xray 的 CPU、有效吞吐及真实连接阻断结果为准。

`zh.3` 修正证书申请前的端口占用检查、绑定结果回读及 HTTPS 就绪检查。全新安装选用证书时，HTTPS 验证失败会保留证书文件并验证已恢复仅本机的 HTTP。独立签发遇到现有监听时保留现有服务，可从证书菜单用 DNS 验证。本地模拟检查覆盖端口占用与空闲、HTTPS 探测参数、证书私钥不匹配、部分写入及重置回读。
