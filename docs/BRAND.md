# V-UI 视觉标识

标识采用蓝、青两条带状路径组成 V，保留白色连接通道和 V-UI 字标。依据为 2026-10-12 确认的设计预览；原始预览保留为设计参考，其 SHA-256 为 `b93a8bad96f1ee030fb9752ea483e86cf3d63460625b558fabf9cd21a5388ace`。这里是人工路径化的可缩放适配，不是像素级自动描摹，也没有替换设计方向。

## 使用

| 资源 | 使用位置 |
| --- | --- |
| [纯图标](../web/brand/vui-icon.svg) | 浏览器 favicon、登录/账户页、后台侧栏与已有导航品牌 |
| [浅色背景字标](../web/brand/vui-wordmark-light.svg) | README 默认背景；深蓝文字 |
| [深色背景字标](../web/brand/vui-wordmark-dark.svg) | README 的深色模式；浅色文字 |

字标保持原预览的上下布局。紧凑页面使用纯图标配合原有 V-UI 文本，不把完整字标缩进小图标。白色通道在深色背景仍保留；不要拉伸比例、旋转、改色或用第三方字体重新拼字。

三个文件都自带同一个 `vui-symbol` 和渐变定义，使用本文件内的 `use` 引用；测试逐项比较这些定义，避免不同入口漂移。为兼容 GitHub 的独立图片呈现，每个 SVG 都可独立加载，不引用其他文件或远程符号。字标文字已经路径化，无字体、脚本、外链或运行依赖。三个 SVG 合计不足 5 KiB；运行包不附带原始大图预览。

页面图片有明确尺寸和 `alt="V-UI"`，相邻可见文字隐藏于无障碍树以避免重复朗读。README 的 `picture` 按配色选择字标，图片仍有文字替代。favicon 使用同一纯图标，不新增下载服务或外部 CDN。

登录、账户、分流、证书 HTML 的 CSP 仅增加 `img-src 'self'` 以加载同源静态标识；其他指令不变，不允许 data/blob、通配或外域图片。资源通过既有 `/ui/brand/` 静态路径提供，并随源码和四目标运行包保留。
