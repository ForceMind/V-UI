# Mihomo YAML 只读面板预览合同

## 阶段与边界

在已完成的本地离线结构预览及中文报告基础上，将相同的只读检查接入现有 `/proxy` 页面。属于路线图 YAML 导入合并的独立前置组件，不实现任意 YAML 导入、转换、合并、保存或应用；不替代既有“导入上游”功能。当前只在本地云端工作树实现和合成验证，不推送、不合并、不发布、不部署，不启新网络服务。

页面必须明确提示：候选和可选基线会在用户点击“生成只读报告”后发送给当前面板服务器解析；不是浏览器内离线解析。不会自动读取服务器当前配置、远程 URL 或 provider。文件读取仅由用户选择触发，原始文件名不传给服务器。输入只留本次页面 / 请求内存，不写浏览器 storage、URL、日志、数据库或配置文件；清空表示撤销可控引用和清空控件，不保证浏览器或操作系统内存擦除。

## 服务端

- 独立 POST `/api/proxy/yaml/preview`；复用现有管理员认证、准确 Origin 与 `X-VUI-Request: 1`、实际 body 2 MiB / 10 秒限制、no-store 响应及固定请求校验错误，不改变认证中间件。
- 严格 JSON 对象：`candidate` 为非空字符串，`baseline` 为非空字符串或 null / 省略，额外字段拒绝。每份 UTF-8 原文最多 1 MiB；JSON 语法与转义占用总 body 额度，因此两份接近 1 MiB 的输入可能仍超总量。
- 调用已有隔离 preview 与严格报告 renderer；预览业务路径不调用 ProxyStore、配置数据库、核心、证书、DNS、外部网络或写文件；管理员认证仍按现有逻辑读取会话，不因此声称整个请求零数据库访问。最多两个并行解析子进程、原 CPU / 内存 / 超时与输出上限不变。
- 成功返回固定版本、`can_apply: false` 和固定中文报告文本；没有源配置、名称、主机、凭据、文件名、输入摘要或转换结果。错误只返回固定代码及 candidate / baseline / pair，不回显底层异常。
- 验证失败 422；解析忙 429；解析器不可用、资源失败或超时 503。成功不授予兼容、合并或应用资格。

## 页面交互

- `/proxy` 上独立“YAML 只读预览”入口与对话框，不与编辑/保存/应用按钮混用；不依赖服务器草稿成功载入。
- 候选及可选基线均可粘贴或选择 UTF-8 文件。空基线表示不比较；空文件、无效 UTF-8、过大文件明确拒绝，不假装成功读取。文件名和内容不插入通知。
- 只在点击生成时发一次 POST，不自动预览或重试。客户端先检查每份 UTF-8 原文与序列化 JSON 总字节上限；服务端始终独立验证。
- 在途重复生成拒绝；编辑输入时取消/失效旧请求并隐藏旧报告。异步文件读取也有每输入槽的代次，编辑、取消、关闭、重开或离页后的旧读取不能写回。
- 关闭、取消/Escape、清空、401、pagehide 清除输入、文件选择及报告，并撤销/失效在途请求与文件读取。pageshow 从空白状态恢复；不靠取消请求本身证明服务端停止解析。
- 响应只有在同一活跃对话框、同一输入代次仍有效时才显示。报告只用 textContent，不使用 innerHTML。固定“不应用 / 未验真实运行”提示不依赖响应内容。
- 请求失败保留当前有效输入供用户手动修正/重试；401 先清理后转登录。解析错误来源可显示固定“候选 / 基线 / 整体”，未知响应或错误只给固定提示。

## 本地验收

1. TestClient 真实隔离解析：候选 / 基线、固定错误、认证 / CSRF、严格 payload、UTF-8 上限、raw body 限额、no-store 与无源值回显；证明不碰 store / core。
2. 实际 JS + HTML 的 Node 合成 DOM / fetch：零自动请求、重复提交、编辑时旧响应、close/reopen、乱序文件读、401、pagehide/pageshow、错误重试、JSON 额度和无 storage / unsafe HTML 使用。
3. 原 52 项 preview / report 测试、完整普通 Python suite、JS 语法、文档链接与 diff 检查；保留 skip 原因。
4. 已将真实认证 / 临时服务器 / 原生 UI 的只读报告、文件读取、取消与原状态保持用例加入现有 `test_proxy_browser.py` 专门门槛；普通本地套件明确 skip，不冒充已验。原生浏览器、真实核心、远端 CI、四目标、发布 / 部署均不在本地证据范围，不重试已知受限执行。

## 本地结果与收口

本地完整普通套件 2231 项：2002 通过、229 条件跳过，无失败，197.447 秒；新 API 12 项和实际控制器 / 模板的 25 项 Node 控制通过。独审后修复了旧延迟 close 事件在重开后清空新输入的风险，合成回归与独审复验通过。原生用例已写入现有专门浏览器 gate 但本地明确未运行，不能把新增 skip 当通过。

范围冻结为此只读候选，不再新增功能。远端同步 / 准确 CI / 合并、真实浏览器及发布 / 部署各自仍待明确范围与执行证据；本地代码完成不是部署就绪。
