## 当前实现契约

- 在线安装使用固定版本；`--with-global-cli` 必须同时提供独立可信的
  `--kit-sha256`，认证完整单目标或四目标 kit，再逐文件核验。
- 控制层以固定 OS `/usr/bin/python3 -B -I -S` 运行，安装前 preflight
  核验 kit、OS 能力及已占用入口；不从服务用户可写的 payload 执行 root 代码。
- 面板安装成功后才发布控制层；后段失败返回非零，明确阶段，并保留可信 kit 供恢复。
  `--with-global-cli --dry-run` 在下载安装动作前拒绝。
- `/usr/local/bin/v-ui` 只指向固定 `/usr/local/sbin/v-ui`；未知占用拒绝。
  普通管理员使用现有 sudo 策略认证，不新增 sudoers、SUID 或常驻控制代理。
- `--interactive` 从 `/dev/tty` 读取缺失的域名、邮箱、管理员名和端口；
  密码沿用现有控制终端读取两次的流程，不通过参数、环境或日志传递。
- 发布器根据最终受验资产生成带安装脚本和 kit 摘要的一行命令。
  固定核心、协议和 UDP 资格边界保持；v0.4.9 是本次获批版本升级。

3. 正常合并，准确 master 独立取得同类验收，不借候选绿灯。
4. 人工 gated workflow 晋升同提交资产，公开新 v0.4.9，不重建或覆盖旧发行。
5. 空白临时 Linux runner 从公开发行入口重新下载，交互配置并在新终端运行 `v-ui`；
   公网下载验证与临时证书 fixture 的范围分别记录，不触碰用户 VPS 或主机信任库。
