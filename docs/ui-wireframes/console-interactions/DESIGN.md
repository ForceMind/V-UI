## 总览

```text
总览                     [刷新状态] [创建节点]
[面板] [Xray] [sing-box] [待处理]
[CPU]                [内存]
[待处理 → 查看位置]  [节点管理] [订阅]
```

| 触发 | 反馈 | 下一步 |
| --- | --- | --- |
| 首次读取或刷新 | 读取中，按钮锁定 | 完成后更新；部分失败只将受影响项标为“状态未确认” |
| 部分读取失败 | 显示失败项，保留仍可确认的值 | 重试读取，回到刷新按钮 |
| 证书待应用或应用失败 | 打开具体使用位置，分列已签发、已绑定、上次生效版本 | 旧证书保持。恢复条件满足后重试此位置，再核对此位置的生效结果 |
| 无待处理 | 暂无待处理项 | 保留常用入口 |
| 会话过期 | 隐藏受保护内容 | 重登后返回原站内页面 |

“创建节点”进入正式面板已有向导，此稿只审入口和进入位置。总览的“运行中”指服务状态，HTTPS 和节点连通性分别核对。

## 节点分享到订阅

```text
节点管理 → 分享连接 → 复制链接 / 显示二维码
                    → 创建订阅 ┐
HTTPUpgrade ───────→ 创建订阅 ┴→ 选节点 → 选格式 → 核对 → 生成地址
                                                    → 导入客户端 → 刷新
```

| 情况 | 反馈 | 恢复入口 |
| --- | --- | --- |
| 分享读取失败 | 分享面板原位报告，暂不显示凭据 | 重试读取 |
| 分享前节点变更 | 节点已变化，关闭凭据入口 | 刷新节点后重选 |
| 自动复制失败 / 二维码未加载 | 原位提示 | 手动复制已选中文本 / 复制连接链接 |
| 无分享或订阅权限 | 对应操作不可用 | 会话过期可重登；权限不足由管理员处理 |
| 所选格式与节点不兼容 | 指明受限节点与可用格式，禁止提交 | 只选兼容格式，或调整节点 |
| 提交时节点修订冲突 | 清空节点选择，保留名称、地址、有效天数和格式 | 刷新节点和订阅，重选后提交 |
| 提交结果未知 | 先暂停重复提交 | 查订阅列表；已有记录则用原地址，遗失时确认更换。确认未创建后才重新提交 |
| 客户端拉取失败 | 核对授权状态、格式及实际错误 | 有效授权可用原地址重试；过期或已撤销则按授权状态重新交付；更换地址会使旧地址失效 |

节点交接以当前节点及其修订为准。示例中普通 VLESS 可用 URI、二维码及所列订阅格式；HTTPUpgrade 只支持 Mihomo YAML，含此节点的订阅不能提交 Base64 或 sing-box JSON。真实产品按每个节点的资格取交集，权限继续由服务端校验。

首次生成结果只展示一次。关闭、离开或会话失效后清除地址显示。关闭分享回到发起按钮；从订阅返回节点时保留筛选并恢复发起位置，找不到原按钮时落在页面标题。窄屏导航从左侧展开，节点行和表单单列，恢复入口紧贴失败提示。

## 终端菜单

```text
V-UI 受管维护  systemd
[服务状态] [待恢复类型 → 原编号]
输入编号
[服务] [诊断与授权]
[版本] [备份与恢复]
[核心] [帮助与退出]
```

| 分组 | 保留快捷编号 |
| --- | --- |
| 服务 | 1 状态、2 启动、3 停止、4 重启 |
| 诊断与授权 | 10 诊断、11 精确放行、13 维护授权 |
| 版本 | 8 准备候选、7 激活候选、12 官方稳定版升级 |
| 备份与恢复 | 5 私有备份、6 恢复备份、9 恢复中断的数据还原、19 双域备份、14 双域恢复、15 恢复中断的双域事务 |
| 核心 | 20 选择记录、16 更新、17 回退、18 恢复中断的核心任务 |
| 帮助与退出 | h 帮助、0 退出 |

| 触发 | 反馈 | 下一步 |
| --- | --- | --- |
| 等待确认 | 显示目标和影响 | 空输入取消。实际确认沿用分支现有 `[yes/N]` 或 `[y/N]` |
| 执行中 | 保留原任务，拒绝重复写入 | 等原任务，服务情况用 1 查看 |
| 操作失败或结果未知 | 核对原任务输出和服务状态 | 用 1 查状态，网络问题用 10；有明确恢复记录则进入对应恢复 |
| 数据还原中断 | 面板保持停机 | **9**，只恢复原记录。原先已停止的服务保持停止 |
| 双域恢复中断 | 保留原双域记录 | **15**，再核对已确认代次和服务状态 |
| 核心任务或远程双域备份中断 | 保留原任务记录 | **18**。远程双域备份中断只恢复服务，不重放备份 |
| OpenRC | 菜单明确能力限制 | 只支持 1 和 8，另有帮助和退出 |

原编号、参数、确认强度和恢复语义以[现行运维契约](../../OPERATIONS.md#终端运维菜单)为准。终端稿演示选项、确认和恢复，生产任务进度及按钮可用性需按实际记录决定。
