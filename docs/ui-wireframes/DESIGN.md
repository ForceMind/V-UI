# V-UI 全站线稿审阅说明

这是独立离线设计稿，不修改正式 `web/` 与 `app/`，不接 API，不生成可连接节点，不执行登录、签发、重启、部署或防火墙操作。全部名称、数值、日志和结果都明确为示例。原产品功能是否可用，以产品代码和对应验收证据为准。

## 查看入口与当前交付

直接打开本目录 [index.html](index.html)，无需服务、安装依赖或网络。首次进入总览，顶部“屏幕索引”列出 37 个主要页面 / 弹窗入口；顶部“手机宽度预览”把画布限制为 390px，菜单从左侧展开。实际窄屏同样采用左侧抽屉。默认桌面左导航固定为 220px，所有已登录页共享位置、分组与选中状态。

线稿审阅版本为 v1，独立于产品版本。当前交付是可点击的完整界面结构与状态稿，不是产品实现；没有浏览器渲染或交互验收。评审目标是页面归属、信息层级、字段和动作覆盖、导航返回逻辑与失败表达，后续视觉稿与正式实现另行推进。

线稿采用白灰黑、细边框、普通字重层级与密集适中的表单 / 表格，不使用装饰大图或大型 hero。交互按钮与链接入口最小高度 44px。手机表单单列、指标两列，宽表格保留横向滚动；不是将桌面表格挤成不可读文字。

## 节点字段覆盖与协议变化

| 表单组 | 字段 / 操作 | 本线稿表达的既有边界 |
| --- | --- | --- |
| 基础 | 备注、端口、核心、协议、状态 | Xray 选择器不展示 HY2 / TUIC；示例数据不创建节点 |
| 基础 | VLESS / VMess UUID | 敏感字段遮蔽；编辑留空保留；新建按已有生成规则 |
| 基础 | Trojan / SS / HY2 / TUIC 密码，TUIC 独立 UUID | UUID 与密码分别留空处理，不把空输入当作清空 |
| 基础 | SS AES-128-GCM / AES-256-GCM / ChaCha20-IETF-Poly1305 | 保留现有算法，不套用额外 TLS / WS 表单 |
| 安全 | TLS / REALITY / None（按协议呈现） | QUIC 强制 TLS；REALITY 演示自动约束为 sing-box / VLESS / TCP，不提供假资格 |
| 安全 | 托管证书 / 手工路径、SNI、ALPN | 普通页面不返回材料路径；手工路径只在特权编辑器；实际可用组合由已有服务端校验 |
| 安全 | REALITY 参考端 / Server Name、Short ID、X25519 私钥 / 配对公钥、Chrome、Vision flow | 私钥仅服务端；单 short ID、显式 SNI、Chrome、固定 Vision；普通分享不带服务端材料 |

| 传输 | XHTTP / HTTPUpgrade 的 Path、Host、Mode | 高级草稿保留入口，明确公开导出仍受阻断；不宣布支持 |
| 传输 | HY2 带宽、Obfs 和密码 | 原生默认资格：带宽留空、Obfs 关闭；高级值为未验收草稿 |

| 路由 | 跟随全局 / 指定直连 / 指定中转 | host 开关独立、共用唯一上游；有效中转拒绝应用 UDP；不符合资格禁止应用，不能静默直出 |

五组切换保留同一份当前标签页内存草稿。基础页切换协议后，安全与传输显示该协议对应字段；状态选择器的失败 / 冲突视图不代表实际校验器。服务端资格、真实生成与真实保存全部未接入。

## 导航与返回契约

### 已确认的当前静态事实

- `web/js/app.js` 初始化主要识别 `#inbounds`；`handleSelect` 中普通内部视图没有同步写入历史，既有 `popstate` 主要关闭编辑 / QR / export，未完成 `currentView` 全量同步。
- routing 与 subscriptions 都跳 `/workspace`，未带各自区块目标；workspace / proxy / certificates 使用各自顶栏，而 index 使用侧栏。静态证据确认壳和跳转契约不一致，不能据此声称已经复现 CSS 把导航移到右侧的浏览器问题。
- 服务端根路径和 account 登录后的固定站内返回，没有保留原目标。既有固定返回有防 open redirect 作用；新设计不能以任意 `nextURL` 替换。
- site 被当前导航逻辑隔离；本线稿维持不可用说明，不恢复旧上传。

### 新的设计契约与线稿实现

1. 一级页面、节点 / 证书子页、分区 `tab` 和弹窗 `modal` 采用本地 `#/...` 路由。刷新能重建页面与对应弹窗；原生 hashchange 驱动 Back / Forward。hash 只包含路由 / 分区 / 弹窗标识，不含密码、token、原始配置或表单草稿。
2. 原则上先关闭弹窗再返回上一页。打开弹窗新增一层历史；在同一弹窗流程里从导入切预览或从创建切一次性地址，用替换当前层，避免积累多个重叠弹窗。始终只显示一个弹窗。
3. 通过索引 / 深链接直接打开弹窗、刷新后的关闭，移除当前 `modal` 并留在所属页面；本标签页常规打开则 Back 关闭。关闭回到所属页面，保留已应用的搜索筛选和内容位置；线稿只有一页示例数据，翻页按钮明确禁用。
4. 页面路径采用白名单；未知页面回总览，未知节点 / 证书子路径退回所属列表。登录返回目标也由同一解析器限制在内部页面；不接收任意外部 URL。登录演示保留内部路径与分区，去掉临时弹窗标识。
5. 未保存表单跨分区保持草稿；跨页面或浏览器 Back 尝试离开时弹出确认。“继续编辑”停留原页；“放弃”清理本次内存草稿后进入目标。线稿在脏表单的浏览器返回处先恢复当前 hash，再按确认进入目标，因此该边界会有一个恢复记录；正式实现应由正式路由器的阻挡机制保持完整历史游标。
6. 密码、订阅令牌、原始导入内容不写 URL、LocalStorage、SessionStorage 或文件。非敏感字段仅在当前标签页内存中保留。密码与原始导入内容不进入草稿缓存，只在当前输入 DOM 暂存，切换重绘 / 关闭后清空；节点保存 / 放弃清空对应草稿；刷新后内存丢失。线稿没有真实 token / 二维码，只给不可连接占位。
7. 弹窗展示关闭按钮、Escape 关闭、键盘焦点循环和返回触发控件的处理意图；属于静态实现，未进行浏览器或辅助技术验证。正式页仍需真实键盘 / 屏幕阅读器验收。
8. 手机菜单始终从左侧展开，入口位置不随页面改变；遮罩点击关闭。左导航 selected 状态依路径所属页面计算，避免仅依点击临时状态。

示例主要路径：`#/overview`、`#/nodes`、`#/nodes/new?tab=security`、`#/nodes/detail?modal=share`、`#/routing?tab=dns`、`#/subscriptions?modal=grant`、`#/proxy?modal=import-preview`、`#/certificates/new`、`#/certificates/detail?modal=bind`、`#/services?modal=restart`、`#/logs?tab=diagnostics`、`#/account`、`#/login`。

## 验收范围与剩余事项

本批静态检查：提取内联脚本后 `node --check` 通过；Node VM 调用 89 个页面 / 分组 / 协议 / 弹窗生成分支通过，6 个非法路由回退断言通过，并检查文本转义、无网络 / storage 调用、CSP `connect-src none` 与无外链依赖。这些是脚本与字符串层证据，不模拟浏览器 DOM。没有启动浏览器、页面服务器、截图、E2E、真实 API 或第三方服务。灰阶线稿不代表视觉与交互已通过验收；布局溢出、触控手感、焦点顺序、真实 Back / Forward 和屏幕阅读器仍需获准后浏览器验证。

固定示例输出不会随所有输入真实计算：YAML 报告、导入候选、配置资格、二维码、证书结果、节点 / 授权列表都是明确标注的结构占位；复制 / 下载只给反馈，没有写剪贴板或下载文件。节点 / 代理表单当前选择可进入核对摘要；这不等于完整业务规则或有效配置生成。

后续正式实现需沿用当前数据 / 权限 / 敏感内容契约，把白名单路由与登录恢复写入正式代码，保留高级字段；通用日志与防火墙仍需单独确认能力和权限范围。本批不变更产品版本、固定核心、正式页面与服务端，也不提交 / 推送 / 发布。
