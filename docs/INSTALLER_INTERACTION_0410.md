# v0.4.10 安装交互修复：计划与证据

## 批准范围

用户报告 v0.4.9 在域名提示处读取空行后仍继续询问，最后才报 Invalid domain；又要求防火墙提示中文化及简写确认。
用户明确批准扩展为 v0.4.10：实现中文提示、y/n/yes/no、默认否/非法重问、域名原地重输，独审、正常 dev/main 合并、通过 Actions 非浏览器构建与实际安装后公开发布。旧 v0.4.9 不覆盖；不做浏览器、不改协议/核心/依赖，不操作用户 VPS 或代同意 CA。

版本分支 `release/v0.4.10`。先前域名短入口候选 `354ee02222a771af2f53f4448cf18ab53fbd5b43` / PR83 保留为前置历史，不继承其 CI 作为 0.4.10 资格。最终准确结果集中在本批承载 PR，不预填未来成功或提交。

## 实现与边界

- setup.sh 在固定 OS Python / 干净环境下读取控制终端域名，空/错即重输；IDNA 与既有 fqdn 一致，合法值显式传给安装器。stdin 密码通道保留，sudo 重入使用单一 --domain=VALUE；物理输入行 4096 bytes 有界读取，超长余尾丢弃，EOF/Ctrl-C 取消。
- 安装器本体同样在邮箱/CA 前循环验证域名。一般输入有界；域名超长整行丢弃后重输，确认超长直接取消，避免把截断 yes 当作授权。
- 确认接受 y/yes 和 n/no（不区分大小写），空行否，非法重问，EOF/中断取消。防火墙检测 backend/detail 结构保持，打印层中文化；自定义/不明确区域不自动修改，端口/协议、云安全组和 CA 同意仍明确。
- 发布套件与短入口分别校验源码身份。开发 0.4.10 时，短命令仍安装固定公开 0.4.9；short-install.yml 独立 checkout 冻结发布源，不能拿新 VERSION/installer 冒充旧已发套件。

## 唯一版本的发布例外

默认门禁仍要求准确提交最新八组、准确 attempt 所有 jobs/steps 成功及必需浏览器步骤存在。
只有显式 installer_only_no_browser=true 且版本恰为 0.4.10 时，才允许列明的 12 个浏览器步骤 skipped。缺失、失败、取消或非浏览器 skip 仍拒绝。
还须证明固定基线 `c138d0062619d498d711e17f86a58a5e8f61a1cf` 为祖先：运行文件仅安装器及发布流程白名单，main.py 必须只有 0.4.9→0.4.10 版本常量变化，web/app/依赖/固定核心及删除、重命名、链接均不允许。该例外不可复用于其他版本，Release 明记浏览器未验证。

## 迭代与验收

1. 域名补丁、中文与确认逻辑、输入边界及权限回归；独立只读审查，修复后针对性复验。
2. 准确候选及正常 dev/main 的 Actions 非浏览器门槛与四目标构建；真实空白 Linux 连续输入空域名、URL、坏标签、合法域名，再输入非法确认和 y，检查没有提前进入邮箱/写服务，继续实际安装、v-ui、重复拒绝、升级备份和重启恢复。
3. 仅晋升准确 main 的已验套件，公开新 0.4.10；核对 tag/19资产/来源、旧 0.4.9 保全。
4. 根据真实公开的 install.sh 与完整 SHA256SUMS 摘要更新短入口默认版本和冻结发布源；独审小更新、正常合并，再从真实 main URL 下载并安装 0.4.10。

初始域名实现独审发现 sudo 重入改变等号形式，已修为单一 --domain=VALUE 并加独立非 root PTY 回归。曾将两个用例共用日志导致夹具误报，已隔离，未放宽断言。
本地 17 项域名/权限/取消模拟与 PTY、3 项超长行边界和独立 sudo 回归通过；沙箱 /dev/tty EPERM 保留，在无网络沙箱外补验。安装器中文/确认/防火墙专项 33 项通过，部分完整旧安装套件本机因 macOS/沙箱能力缺失失败，留待 Linux Actions；不得当作相关功能已验。所有构建与真实安装均放在 Actions，不在本机下载 Linux 发行 ZIP。
