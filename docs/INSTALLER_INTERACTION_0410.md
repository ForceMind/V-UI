## 实现与边界

- setup.sh 在固定 OS Python / 干净环境下读取控制终端域名，空/错即重输；IDNA 与既有 fqdn 一致，合法值显式传给安装器。stdin 密码通道保留，sudo 重入使用单一 --domain=VALUE；物理输入行 4096 bytes 有界读取，超长余尾丢弃，EOF/Ctrl-C 取消。
- 安装器本体同样在邮箱/CA 前循环验证域名。一般输入有界；域名超长整行丢弃后重输，确认超长直接取消，避免把截断 yes 当作授权。
- 确认接受 y/yes 和 n/no（不区分大小写），空行否，非法重问，EOF/中断取消。防火墙检测 backend/detail 结构保持，打印层中文化；自定义/不明确区域不自动修改，端口/协议、云安全组和 CA 同意仍明确。
- 发布套件与短入口分别校验源码身份。开发 0.4.10 时，短命令仍安装固定公开 0.4.9；short-install.yml 独立 checkout 冻结发布源，不能拿新 VERSION/installer 冒充旧已发套件。
