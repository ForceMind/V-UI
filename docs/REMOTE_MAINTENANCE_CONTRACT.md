# 临时远程维护权限契约

## 使用流程

已公开v0.4.19将上限扩展为180天（15552000秒）；旧18及更早已签发授权的截止不会因此改变。管理员在“远程维护”或本机 root `v-ui` 创建授权，选择只读或需要的操作权限、有效期；默认仍为30分钟，网页保留30分钟/1小时/2小时并增加180天，终端保留分钟输入并接受180天/180d。页面只在本次展示完整链接。链接形如 `https://panel.example/maintenance#grant=<随机凭据>`；fragment 不进入 HTTP 请求、代理日志或 Referer。API 客户端提取 fragment 后通过 POST JSON 兑换，页面同样兑换并清除 fragment。兑换成功只返回一次 Bearer 维护会话和原授权截止时间、scope、自描述操作目录；不设置管理员 cookie。不因晚兑换重新获得180天，不自动延长旧授权或扩充权限。180天内持有会话凭据者可按授权持续操作，管理员可随时撤销。分享链接是敏感授权，不是公开诊断页面。

兑换凭据与维护会话各至少 256 bit 随机，数据库只存 SHA-256；兑换原子单次使用。会话最长不超原授权截止时间。管理员撤销、停用、改密后立即拒绝后续请求。失效凭据固定中文错误；兑换受持久化速率限制。来源 Host 必须符合面板既有配置；不得启用通配 CORS、TLS 跳过或 query 认证。浏览器请求继续强制准确 Origin/X-VUI-Request；无 Origin 的专用 API 客户端必须使用显式 Bearer，不能借 cookie 越过 CSRF。

创建/列举/撤销授权仅限本地管理员 cookie 会话或明确的本机 root 入口；远程维护凭据无此能力。前端不将凭据写入 localStorage/sessionStorage、URL query、遥测或控制台。恢复管理员账号不在远程权限内。

## 权限

权限用服务器固定 scope 字符串表示，不允许路径前缀式全 API 放行。默认只读，其余显式选择：

| scope | 能力 | 不能隐式获得的能力 |
|---|---|---|
| diagnose | 状态、节点公开摘要、协议资格、证书摘要、路由状态、维护任务与脱敏诊断 | 节点连接凭据、配置修改、文件读取 |
| nodes | 节点创建、特权编辑读取、修改、启停和应用核心 | 节点删除、导出分享、修改管理员 |
| share | 显式节点 URI/配置导出、订阅创建和轮换 | 删除节点或订阅、解除协议资格限制 |
| relay | 导入上游、选择上游、保存/检查/应用既有代理策略、每入口出口配置 | UDP 中转扩围、静默 DIRECT 回退 |
| certificates | 申请/续期/自动续期/绑定/重试已有证书工作流 | 私钥下载、代替用户接受新的真实 CA 条款 |
| operate | 固定 V-UI 服务启停/重启、私有备份任务 | 任意 shell、任意文件路径、SSH/防火墙/系统用户修改 |
| upgrade | 官方稳定版本检查、校验/备份/升级/健康验证、查询持久任务 | 自选 URL、任意候选代码、覆盖旧发布资产 |
| destructive | 明确开放节点/订阅删除和已有备份恢复等受支持删除/恢复入口 | 管理员凭据、系统通用管理 |

节点修改包含 routing_mode 时必须同时有 relay；维护请求体不能通过组合 payload 绕过 scope。每条既有业务路由用准确方法/路径匹配列入权限表，未列明直接 403。原实例修订、事务、If-Match、导出 allowlist 和证书保护必须复用，不能为远程入口另建弱化 CRUD。

## API 与任务

授权路由集中 `/api/maintenance`：管理员 GET/POST `/grants`、DELETE `/grants/{id}`；公开但受限 POST `/exchange`；维护 GET `/session` 和 `/catalog`；GET `/audit` 只读安全字段。节点等操作沿用既有 API，Authorization: Bearer 加自定义 X-VUI-Request: 1。目录描述准确 method/path/scope、必要修订和中文用途，方便维护客户端发现，不能把允许操作解释成任意执行权限。

系统维护由固定 root 控制代码通过本地受限通道执行，面板仍为非 root。仅服务用户可连接（核验 Unix peer 身份）；消息大小、字段、操作、并发和超时有界，默认拒绝未知键。持久任务 ID 由服务端生成，客户端不得提供文件路径、unit 名称或命令。root 组件不导入用户可写应用代码。GET `/tasks/{id}` 返回安全状态，POST `/tasks` 只接受列明操作和必要的固定格式参数。任务先登记后执行，队列/升级锁互斥，重启后仍可查询；未完成任务不得显示成功。

升级来源只接受 ForceMind/V-UI 正式稳定发布/固定官方入口的 HTTPS 信任边界，核对正式版本、受验 SHA-256/完整清单及目标。绝不运行请求提供的脚本 URL、shell 字符串、归档路径或环境变量。升级读取 root 原配置，保留业务数据；先备份，再通过现有部署链激活/启动并做 TLS 健康验证，失败保留恢复证据。不得为无人值守升级接受新的 CA 条款；需要新授权或修复残留时明确停止。

独立维护组件必须在面板停止/升级期间继续执行。面板恢复后原维护会话在未到期/撤销/管理员变更的前提下可继续查询任务。面板完全不可达时仍需终端恢复；链接不能绕过 DNS/TLS/网络不可达。

## 审计与页面状态

审计只记固定操作、授权 ID、时间、状态码/任务 ID，不保存 header、token、完整 URL、请求体、配置、连接 URI、证书私钥、原始异常和用户输入。诊断输出复用脱敏，响应均 no-store。授权管理页能查看剩余时间/权限/状态、撤销；复制失败允许本次手动选中，关闭/离页/401 清除敏感显示。在途旧请求不能覆盖新会话。

“节点管理”提供创建、编辑、启停、分享、订阅、中转上游导出入口，区分已保存与已应用出口。“代理与中转”明确两个方向：此机→上游、另一机→此机；继承/直连/中转沿用原资格，中转仅 TCP。分享失败显示安全中文原因与重试，不以关闭安全检查换取成功。不支持的 Xray 配置/协议明确解释，不能伪造可用链接。

## 交付边界

本契约授权实现、测试、独审与开发 PR，不授权公开发布或进入用户 VPS。用户之后实际提供链接并说明维护目标时，按那次授权操作服务器。构建、真实核心和安装验收只 Actions；线稿/代码/合成 DOM 不能宣称真实浏览器验收。

## 本批实现补充

- 远程备份恢复只接受本组件成功备份任务的 32 位 ID，不接受路径或外部 SHA。恢复会清空维护授权/会话，防止旧备份复活已撤销权限；完成结果仍在 root 私有任务记录，可从终端查询。已受理任务继续完成或安全失败，撤销/到期阻止后续请求，不强杀在途升级。
- 系统远程任务首期 systemd；OpenRC 的原有支持保持，远程系统变更明确不可用，不能伪装全平台支持。
- 维护会话的证书首次申请须管理员先行授权；旧 bind-inbound 路由无实例修订，不向远程开放。使用 nodes+certificates 和 guarded PUT 节点绑定；手工文件路径不向远程暴露。
- Xray 分享此次仅限定 VLESS RAW/TCP TLS、单用户、空 flow；客户端 TLS 验证开启，不承诺 UDP 或 Xray 中转资格。固定核心/客户端真实测试通过前不声明新增分享已获资格。
