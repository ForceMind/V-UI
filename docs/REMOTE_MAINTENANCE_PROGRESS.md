## 必需验收

- 链接不含可发送到服务器的 query 凭据；只显示一次、一次兑换、过期、撤销、管理员改密失效、并发兑换仅一次成功，数据库/日志不保存原 token。
- 只读授权不能写；节点/分享/路由/证书/系统操作按独立 scope 判断，未列明路由默认拒绝；维护会话不能再创建授权、改管理员或访问文件托管。
- 有状态修改沿用实例修订、If-Match、应用检查、证书和导出资格；敏感响应 no-store，审计不记录请求/响应正文或凭据。
- 真实 API 使用维护会话创建/编辑节点、显式分享、配置中转、撤销授权后拒绝。脱敏错误可诊断分享失败，但不放宽未获资格协议。
- 固定系统维护组件不接受任意命令/路径/下载 URL；升级由独立任务执行，备份和配置保留，重启后可查状态。失败及中断状态不假报成功，已有安装不能当新装初始化账户。
- `sudo v-ui` 不选择升级时无下载；选择升级后才获取可信官方入口，终端本地与远程走同一受限升级链。
- 既有工作流、真实固定核心、四目标、旧版本升级验收保持。浏览器明确未验证，未公开发布不称上线。
