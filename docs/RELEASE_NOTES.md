# V-UI 0.4.13

新安装自动生成随机管理员用户名和强密码，安装完成后在当前终端显示，随后可登录面板修改。已有账号、密码、节点、订阅和配置保留，升级或修复不重置。

取消本机及云安全组的重复 yes 确认，只读检查本机规则并提示具体端口缺口；无法确认上游网络时明确提示，不将本机允许视为公网可达。默认不修改防火墙，首次 CA 条款仍须明确同意，匹配域名的真实已有授权可复用。

本版按用户明确批准采用仅限0.4.13安装自动化范围的严格非浏览器验收；浏览器未验证。准确构建/真实安装/四目标和发布结果见[本版记录](INSTALLER_AUTOMATION_0413.md)。公开发布必须经过准确主线门禁，不覆盖旧版标签或资产。
