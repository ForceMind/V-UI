# V-UI 0.4.12

修复可移植Python在Ubuntu等系统中默认CA目录延迟加载、根证书枚举为空导致的INVALID_CERTIFICATE_MATERIAL。默认加载系统bundle/受索引目录，同时保留显式根和SSL环境隔离；未知CA、域名、配对、有效期和证书链仍拒绝。

新增CA仓库不可用/证书链验证失败的固定错误分类，不回显PEM、私钥或原始异常。配置、管理员、用户、节点、订阅和失败恢复保持。已有安装仍先显示管理菜单，选择升级或续装才下载。

本版按用户明确批准进行严格非浏览器验收；浏览器未验证。准确构建/真实安装/四目标和发布结果见[本版账本](CERTIFICATE_SYSTEM_CA_0412.md)，不将候选称为已发布，不覆盖旧版tag/Release/资产。
