# V-UI 0.4.16

新增TLS节点默认使用已有托管证书：唯一适用正式有效证书自动选，多张由用户明确选择；读取失败可重试，SNI冲突在保存前以中文提示。编辑保留原有绑定和手工路径，不把新建默认覆盖到旧节点。

Xray VLESS RAW/TCP TLS空flow支持托管证书的新建、编辑、续期和恢复。统一资格分类，保持REALITY排除、机器错误码、desired/applied与失败保旧、停止待应用以及材料保密边界；其他未验Xray协议/传输不扩大。

修复Xray默认IPv4通配监听被核心实现为双栈::时的启动就绪误判。只在自有子进程接收了实际IPv4探测连接、完整元组匹配后认可双栈，保留loopback精确检查、原5秒预算、UDP与sing-box规则；外部IPv4服务不能冒充。

保留原配置、账户密码、证书、节点、订阅和旧版资产。构建、四目标、固定真实核心、真实安装及公开旧版保数据升级均在GitHub Actions验收；仅本版严格非浏览器发布例外，浏览器未验证。准确源与历史失败见[本批记录](TLS_CERTIFICATE_BINDING_FIX.md)。发布只晋升准确主线已验同源制品，不重建或覆盖旧标签/资产。
