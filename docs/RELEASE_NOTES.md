# V-UI 0.4.15

全站统一桌面左导航、手机抽屉、面包屑和账户入口。节点表单按基本信息、安全、传输、路由和高级项分组，保留原字段、API、权限及协议边界。

页面使用固定站内URL，修复工作区目的地、返回/前进及弹窗历史。未保存/提交中的操作保留离页保护；跨页前同步清空敏感链接并取消未完成请求，登录恢复只接受固定站内目标。

普通安装保留真实监听、证书及HTTPS就绪检查，不因无法判断云安全组而重复要求确认。终端菜单10提供分层只读诊断，11在明确确认后对安全识别的已启用UFW/firewalld精确放行；不自动启用防火墙、不猜zone、不修改SSH、云安全组或自定义规则。默认节点TCP端口是声明，不代表已创建节点。

保留已有配置、账户密码、证书、节点及订阅；旧版升级沿用备份和失败恢复。构建、四目标及公开v0.4.14到本版的真实安装/升级验收在GitHub Actions完成。按本版明确授权采用严格非浏览器验收，浏览器未验证；不将静态/单元测试描述为视觉或浏览器交互验收。准确提交和历史失败见[统一记录](UI_REDESIGN_PROGRESS.md)。发布只晋升准确主线已验制品，旧标签和资产不覆盖。
