本版修复已有安装的终端配置流程，发布状态以官方 Release 为准；短入口只在公开发布并核对真实摘要后更新。

- 已有安装先验证并显示原配置，选择沿用升级、继续未完成安装、修改或取消；回车默认取消。
- 域名、邮箱、面板端口、监听 IP 及节点端口预检声明有原值默认、当场校验和变更确认。已有管理员、密码、实际节点和证书模式保留。
- 已有安装停服备份，持久保存可恢复的配置/证书绑定/联系人/原运行指针。失败不删库，不执行会撤销会话和订阅的全库恢复；中止或断电后下次安装先恢复。
- 构建和真实安装验收在 Actions，浏览器未验证。未访问用户 VPS 或代同意实际域名的 CA 条款；公网安装仍需操作者核对防火墙及云安全组。

范围、限制、准确候选和门槛结果见 [已有安装账本](INSTALLER_EXISTING_0411.md)。用户已明确批准本次纯安装修复采用严格、仅限 0.4.11 的非浏览器发布例外；不覆盖旧 Release/tag/资产。

## v0.4.10 历史发布记录

本版修复 Linux 终端安装交互，不新增代理协议或改变固定核心。

## 改动

- 域名为空或格式无效时立即提示重输，合法后才继续邮箱、账号与端口配置；保留 IDNA 规范化和严格域名规则。
- 安装、防火墙与确认提示中文化；接受大小写 y/n/yes/no，空回车默认否，非法回答原地重问，EOF/Ctrl-C 取消。
- 自定义 nftables/iptables 仍不自动修改。实际入站区域、云安全组和精确协议/端口必须由操作者核对；回答 y 不等于程序已验证公网可达。
- CA 条款及公开证书记录仍需操作者明确同意；密码由控制终端读取，不放入命令行。
- 短入口在系统 Python 中预检域名，保留固定环境、sudo、完整性校验及 v-ui 菜单。

## 安装

正式公开并更新可信摘要后，从项目 README 复制短命令：

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/ForceMind/V-UI/main/setup.sh)
```

安装后输入 v-ui。已有实例升级前应先备份并按运维指南显式使用 --upgrade；不会因重跑普通安装而覆盖现有安装。
本 Release 下方还保留按真实资产生成的固定摘要长命令。短入口只在公开后切换可信版本；旧 v0.4.9 的标签与资产不覆盖。

发布门禁只为 0.4.10 提供显式例外，并核对固定基线的源差分：不允许前端、应用逻辑、运行依赖或固定核心改变；仅明列浏览器步骤可跳过，其他失败、缺项、取消或跳过均拒绝。
准确提交、jobs/steps、四目标包与独审证据由发布记录关联。真实安装使用空白 Linux、假凭据及临时提供证书，不代表已部署用户 VPS、真实域名 CA 签发或公网线路验收。

升级已有实例前保全离机备份。本版沿用订阅授权与节点实例身份绑定；未绑定实例的旧授权须重新选择节点、创建授权并更新客户端 URL。
