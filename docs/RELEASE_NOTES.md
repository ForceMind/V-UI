# V-UI 0.4.14

修复面板完整性校验和初始化超过约10秒就被安装器提前停止的问题。启动请求起采用最长120秒的有界就绪预算，只有真实HTTPS、域名与鉴权检查通过才继续；不跳过程序/运行时完整性或TLS验证。

服务明确失败及时提示，在回滚前采集有界脱敏状态和启动事件。保留已有配置、账号、密码、证书、节点及订阅；诊断失败不阻止恢复。新安装继续自动生成凭据，已有安装继续本地菜单优先。

按用户明确批准采用仅限0.4.14的严格非浏览器验收；构建和真实慢启动/失败恢复均GitHub Actions，浏览器未验证。准确资格与保留失败见[本版记录](STARTUP_READINESS_0414.md)。公开发布只晋升准确主线已验制品，旧标签和资产不覆盖。
