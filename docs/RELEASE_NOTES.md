# V-UI 0.4.17

新增临时远程维护：管理员在面板或终端生成限时、一次兑换、可撤销的维护链接，明确授权节点创建/编辑/启停、分享与订阅、中转、已有证书、服务操作、备份恢复或升级。凭据仅显示一次，服务器只存摘要；原实例修订、If-Match、TLS、事务和普通响应保密边界保持。

全局 `v-ui` 新增12在线升级和13中文维护授权。打开菜单不下载，仅选择并确认升级才获取官方稳定套件；核对完整摘要，只下载本架构包，先备份再升级并校验HTTPS。独立受限系统维护组件在面板重启期间继续执行任务，不接受任意命令、路径或下载地址。OpenRC原支持保持，新增远程系统任务限systemd。

节点页与代理/中转页明确管理、分享和两个中转方向。Xray普通分享只支持单用户VLESS RAW/TCP TLS、空flow；严格校验配置，URI订阅/YAML用固定Xray与stock Mihomo真实转发，错误CA必须拒绝。不扩大Xray中转或应用UDP资格。

保留原配置、账户密码、节点、订阅、证书及旧版资产；恢复备份清除维护授权与会话，避免复活已撤销权限。构建、四目标、真实核心、安装/维护及公开旧14/15/16保数据升级均在GitHub Actions验收；仅本版严格非浏览器发布例外，浏览器未验证。候选升级tail使用受信本地transport与同版本选择，官方版本/摘要/单目标下载另有单元边界；公开后另做匿名安装和真实main短入口验收。
