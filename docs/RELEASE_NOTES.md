# V-UI 0.4.19

网页增加180天维护授权选项；终端可输入180天、180d或对应分钟数。API、业务服务和固定服务用户启动器同步允许最长15552000秒，默认仍为30分钟、只读权限。

链接保持一次兑换，兑换后的会话使用原授权截止；第179天兑换不会重新获得180天。撤销、管理员改密/停用及到期后继续拒绝访问，权限和路由不扩大，凭据仅hash保存，不自动续期旧授权，无数据库迁移。原配置、账户、节点、订阅和证书保持。

用户已批准独审、正常dev→main合并、公开19及短入口更新；产品冻结后只补本版本严格发布门禁与说明。构建和真实安装仅GitHub Actions，浏览器未验证。不覆盖18等旧版资产，不修改VPS。准备、实际公开和短入口切换状态分别记录在[本批记录](LONG_MAINTENANCE_0419.md)和承载PR，不将准备当作已发布。
