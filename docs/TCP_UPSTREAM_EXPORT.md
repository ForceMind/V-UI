# 将一个 V-UI 节点导入另一实例作为 TCP 中转上游

## 适用版本与范围

这是 D1 源码功能的操作说明，准确候选、主线验收及未通过记录以承载 PR 为准；文档本身不代表验收通过或已经发布。公开的 v0.4.8 安装器基线不包含此功能，不要覆盖该版本资产。

本功能提供独立的“导出为中转上游（仅 TCP）”入口，支持单用户 sing-box VLESS 直连 TCP + TLS 或 REALITY/Vision，输出 URI 或单节点 Clash YAML。普通“分享”和已有订阅继续按原规则生成设备配置；它们可能包含应用 UDP 选项，仍会被严格上游导入拒绝。请主动选择这个专用用途，不要手动删掉未知字段伪装成兼容。

## 操作步骤

1. 在海外出口实例的“入站节点”找到合资格节点，点击“导出为中转上游（仅 TCP）”。节点须已启用、未设置定时过期、只有一个 UUID，并符合已有 TLS 或 REALITY 配置约束。
2. 显式填写该节点可达的服务器主机名或 IP。不包含 `https://`、端口、路径、用户名或 IPv6 方括号。这里填写的是目标地址；TLS SNI 来自已保存节点，不由输入主机覆盖。目标地址 ASCII 大小写会统一为小写，其他字段保持。
3. 选择 URI 或单节点 Clash YAML，勾选 TCP-only 与凭据提示后点击“生成上游配置”。复制或下载仅在成功后可用；文件名为 `upstream-tcp.txt` 或 `upstream-tcp.yaml`。
4. 到国内中转实例的“代理与中转”页面，点“导入 URI / JSON / YAML”，选择格式并粘贴刚生成的内容。先预览，再明确选择候选、保存上游，并在“唯一上游”中明确选中。导入/保存本身不会应用网络配置；当前三态候选中，两个开关均关闭时也可完成上游选择和应用。
5. 保存草稿，完成检查、核对并应用。当前三态候选的“服务器本机显式代理”和“默认入口中转”独立且默认关闭；后者只影响“跟随全局”入口。首次“指定中转”应先应用所选上游，再启用节点，无需临时开启默认中转，详见[每入口使用说明](PER_INBOUND_ROUTING.md)。
6. 使用面板分层诊断，并用真实设备经中转执行 HTTPS 请求确认出口。面板本机测试通过不表示外部设备路径已测。

服务器自身开关提供带鉴权的 loopback 显式代理。终端工具须按[双开关使用说明](DUAL_PROXY_RELAY_M3.md)配置代理；不会自动接管整台服务器、ICMP ping 或不支持代理的应用。

## 失败时如何理解

- **不具备导出资格**：检查单用户、sing-box/VLESS、直连 TCP、启用状态与定时过期。WS、gRPC、其他协议/核心、多用户、未知高级字段或 TLS 跳过校验不会被自动删改来生成文件。
- **无效的字面主机/IP**：去除协议、路径或端口，填写正确目标；不要通过忽略证书验证来绕过错误。
- **没有权限或会话失效**：使用当前实例管理员会话。普通订阅授权不允许调用专用导出。
- **导入成功、应用失败**：出口可达性、目标地址安全校验和核心实际配置仍须通过。导出只做本地解析，不访问服务器，不是可达性证明。
- **海外上游失效**：已受保护流量继续失败关闭，不以 direct 或普通 DNS 兜底。原普通模式的未受保护流量保持原行为。

国内服务器需要能够连接海外上游。该功能适用于目标网站直连受到干扰、但代理上游可以建立连接的场景；不能修复上游本身完全不可达。

## 凭据与兼容边界

导出含客户端 UUID 及必要连接字段，请只交给获授权的管理员。不要贴入问题报告、公开聊天或不可信转换网站。面板不会将内容存入浏览器 localStorage/sessionStorage 或 URL；关闭、换节点/主机/格式、撤销确认、刷新、请求失败或会话结束会清除显示并阻止旧响应恢复。已由用户复制或下载到其他程序/文件的内容不由面板自动清除。

服务端私钥、证书和材料路径不出现在导出中。REALITY 公钥/short ID 属于客户端连接信息，仍按连接凭据处理。

- 不增加 Shadowsocks、Trojan、VMess、WS/gRPC、HY2/TUIC 等上游中转资格；普通节点能力不受删除。
- 单节点 YAML 明确 `udp: false`。URI 不包含 UDP 编码不等于任意客户端关闭 UDP；接收实例由既有 TCP-only 出站及入口 UDP 拒绝策略执行边界。
- 不开放通用应用 UDP 双跳、全机 TUN 或整个 Clash 客户端规则迁移，不变更系统代理、DNS、防火墙或路由。
- 不创建新的订阅令牌或扩大 grant 权限，不改变双开关默认值、配置 schema、固定核心或正式版本。

工程验收、接口错误和测试门槛见[冻结契约](TCP_UPSTREAM_EXPORT_CONTRACT.md)。
